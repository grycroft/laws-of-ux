---
name: ux-review
description: Review the current screen, component or diff against the Laws of UX checklist and fix what fails
---
Review the UI code in the current selection, open file or diff using the `laws-of-ux` skill.

1. Identify the user's primary goal and primary action for the screen.
2. Run every item in the skill's review checklist. For each failure, cite the law, the file and line, and the concrete fix.
3. Rank findings by user impact (blocks the task, slows the task, polish).
4. Apply the fixes unless asked for a report only, then summarise what changed and any trade-offs that need user testing.
